# Tutorials

Four lessons: three in order, from install to a finished optimization, and one on the field outside the plasma. Each one is
a single path with visible results at every step and runs on a plain
`pip install vmex` CPU install. The decks they use are in the repository's
`examples/data/` directory, and the scripts they include from `examples/`
are executed by CI.

```{toctree}
:maxdepth: 1

first-equilibrium
first-gradient
first-optimization
exterior-field
```
